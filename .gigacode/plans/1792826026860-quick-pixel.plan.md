# Plan: Risk Registry API Implementation

## Overview
Implement 4 endpoints for the Risk Registry:
1. `GET /v1/risks` — List all risks
2. `POST /v1/risks` — Create a risk (draft)
3. `PUT /v1/risks/{id}` — Edit risk draft
4. `POST /v1/risks/{id}/assess` — Initial risk assessment

## Architecture Notes

- **No permission checking infrastructure exists** for granular rights (`view_risk`, `create_components`, etc.). All controllers currently use `[Authorize(Roles = "ADMIN")]`.
- **Risk entity exists** in Domain layer with business logic (status transitions, classification).
- **No repository, service, or controller exists** for `Risk`, `RiskProcess`, or `RiskAssessment`.
- **Database schema** uses varchar status: "Draft", "Open", "InTreatment", "Accepted", "Closed".
- **Rights are stored** in `roles.rights` → `roles.role_rights` → `roles.user_roles` → `roles.users`.

```csharp
// GET /v1/risks
public Task<RiskListItemDto[]> GetAllAsync(int userId, CancellationToken ct);
// Checks view_risk permission, loads all risks, for risks without active assessment shows "-" in assessment columns

// POST /v1/risks
public Task<int> CreateAsync(int authorId, CreateRiskRequest request, CancellationToken ct);
// 1. Check create_components permission
// 2. Check all processIds are active
// 3. If assetId: check asset is active and has hourCost > 0
// 4. Validate required fields (title, description, hazardId, categoryId)
// 5. Create Risk with status "Draft"
// 6. Create RiskProcess (one isPrimary = true)
// 7. Return riskId

// PUT /v1/risks/{id}
public Task<int> UpdateAsync(int riskId, int userId, UpdateRiskRequest request, CancellationToken ct);
// 1. Check edit_components permission
// 2. Check risk status is "Draft"
// 3. Check user is owner of primary process
// 4. Validate completeness
// 5. Check asset (if provided): active + hourCost
// 6. Save passport without changing status, author, or process links
// 7. Return riskId

// POST /v1/risks/{id}/assess
public Task<AssessRiskResponse> AssessAsync(int riskId, int userId, AssessRiskRequest request, CancellationToken ct);
// 1. Check assess_risk permission
// 2. Check status is "Draft" and no active assessments exist (409 if concurrent)
// 3. Validate required fields
// 4. If assetId = null: use request.lossAmount directly
// 5. If assetId filled: calculate downtimeTotalHours = weeks*168 + days*24 + hours; lossAmount = downtimeTotalHours * hourlyDowntimeCost (HALF_UP to 2 decimals)
// 6. Determine impactLevelId by monetary range (find ImpactLevel where loss <= amount <= max)
// 7. riskScore = likelihoodWeight * impactWeight
// 8. Determine acceptanceLevel by thresholds (Owner/Director/Ceo based on score ranges)
// 9. Save Assessment with isActive = true, responseMode = null
// 10. Transition risk to "Open" status
// 11. Return assessmentId, riskScore, acceptanceLevel, riskStatus
```

### Step 6: Create RisksController

**File: `src/Presentation/Controllers/RisksController.cs`**

```csharp
[ApiController]
[Route("v1/risks")]
[Authorize(Roles = "ADMIN")]
public sealed class RisksController : ControllerBase
{
    private readonly RiskService _service;
    private readonly ILogger<RisksController> _logger;
    
    // GET /v1/risks
    [HttpGet]
    [ProducesResponseType(typeof(IReadOnlyList<RiskListItemDto>), StatusCodes.Status200OK)]
    [ProducesResponseType(StatusCodes.Status401Unauthorized)]
    [ProducesResponseType(StatusCodes.Status403Forbidden)]
    public async Task<IActionResult> GetAll(CancellationToken ct)
    
    // POST /v1/risks
    [HttpPost]
    [ProducesResponseType(typeof(CreateRiskResponse), StatusCodes.Status201Created)]
    [ProducesResponseType(StatusCodes.Status400BadRequest)]
    [ProducesResponseType(StatusCodes.Status401Unauthorized)]
    [ProducesResponseType(StatusCodes.Status403Forbidden)]
    public async Task<IActionResult> Create([FromBody] CreateRiskRequest request, CancellationToken ct)
    
    // PUT /v1/risks/{id}
    [HttpPut("{id:int}")]
    [ProducesResponseType(typeof(UpdateRiskResponse), StatusCodes.Status200OK)]
    [ProducesResponseType(StatusCodes.Status400BadRequest)]
    [ProducesResponseType(StatusCodes.Status401Unauthorized)]
    [ProducesResponseType(StatusCodes.Status403Forbidden)]
    [ProducesResponseType(StatusCodes.Status404NotFound)]
    public async Task<IActionResult> Update(int id, [FromBody] UpdateRiskRequest request, CancellationToken ct)
    
    // POST /v1/risks/{id}/assess
    [HttpPost("{id:int}/assess")]
    [ProducesResponseType(typeof(AssessRiskResponse), StatusCodes.Status201Created)]
    [ProducesResponseType(StatusCodes.Status400BadRequest)]
    [ProducesResponseType(StatusCodes.Status401Unauthorized)]
    [ProducesResponseType(StatusCodes.Status403Forbidden)]
    [ProducesResponseType(StatusCodes.Status404NotFound)]
    [ProducesResponseType(StatusCodes.Status409Conflict)]
    public async Task<IActionResult> Assess(int id, [FromBody] AssessRiskRequest request, CancellationToken ct)
}
```

## Key Algorithm Details

### Assessment Calculation (Step 4, AssessAsync)
```
if (assetId == null):
    lossAmount = request.lossAmount
else:
    downtimeTotalHours = weeks*168 + days*24 + hours
    hourlyDowntimeCost = asset.hourCost
    lossAmount = Round(downtimeTotalHours * hourlyDowntimeCost, 2, HALF_UP)

impactLevelId = FindImpactLevel where loss <= lossAmount <= maxLoss
(riskScore) = likelihoodWeight * impactWeight

// Acceptance level:
if (riskScore <= ceoMaxScore): acceptanceLevel = "Owner"
else if (riskScore <= directorMaxScore): acceptanceLevel = "Director"
else: acceptanceLevel = "Ceo"

riskStatus = "Open" (was "Draft")
```

### Risk List (GET)
- Load all risks (no org context filter)
- For each risk, check if active assessment exists
- If no active assessment: likelihood="-", impact="-", riskScore=null
- Join with risk_processes to get process/directorate/owner info
