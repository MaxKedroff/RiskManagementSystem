# Plan: Risk Lifecycle Management (Accept, Treat, Split, Transfer, Reassess, Close)

## Overview
Implement 6 endpoints for risk lifecycle management after initial assessment:
1. `POST /v1/risks/{id}/accept` — Принять риск
2. `POST /v1/risks/{id}/treat` — Выбрать режим "Обработать"
3. `POST /v1/risks/{id}/split` — Разделить риск
4. `POST /v1/risks/{id}/transfer` — Передать риск
5. `POST /v1/risks/{id}/reassess` — Вернуть на переоценку
6. `POST /v1/risks/{id}/close` — Закрыть риск

## Key Design Decisions

### "AwaitingReassessment" status
- **Не существует в RiskStatus enum** — нужно добавить `AwaitingReassessment = 6`
- Используется в transfer и reassess операциях

### Blocking measures (блокирующие меры)
- **Не реализовано в БД** — определяем на уровне бизнес-логики
- **Non-terminal (блокирующие)**: treatment со статусом "Planned" или "InProgress"
- **Terminal (завершённые)**: treatment со статусом "Completed" или "Cancelled"
- Риск с non-terminal treatment не может быть закрыт или принят

### ResponseMode
- `RiskAssessment.ResponseMode` — nullable string, всегда null в текущем коде
- Возможные значения: "accept", "treat", "split", "transfer"
- Нужно добавить метод `SetResponseMode(string)` в RiskAssessment или обновлять через репозиторий

### System comments
- RiskComment с `EntityType = "Risk"`, `EntityId = riskId`
- Автор комментария = userId пользователя, который выполнил действие
- Текст комментария — системный (например: "Риск закрыт пользователем X")

// POST /v1/risks/{id}/accept
public async Task<AcceptRiskResponse> AcceptAsync(int riskId, int userId, CancellationToken ct)
{
    // 1. Check accept_risk permission
    // 2. Check status is "Open"
    // 3. Check active assessment exists
    // 4. Check assessment has acceptanceLevel set
    // 5. Check responseMode is null
    // 6. Check no blocking measures (non-terminal treatments on any linked process)
    // 7. Update assessment.responseMode = "accept"
    // 8. Update risk.status = "Accepted"
    // 9. Return riskId, riskStatus, responseMode
}

// POST /v1/risks/{id}/treat
public async Task<TreatRiskResponse> TreatAsync(int riskId, int userId, CancellationToken ct)
{
    // 1. Check edit_components permission
    // 2. Check status is "Open"
    // 3. Check active assessment with responseMode = null
    // 4. Check primary process link exists
    // 5. Update assessment.responseMode = "treat"
    // 6. Return riskId, responseMode
}

// POST /v1/risks/{id}/split
public async Task<SplitRiskResponse> SplitAsync(int riskId, int userId, SplitRiskRequest request, CancellationToken ct)
{
    // 1. Check split_risk permission
    // 2. Check status is "Open"
    // 3. Check active assessment exists
    // 4. Check all request processIds are active
    // 5. Check processIds are unique (>= 2)
    // 6. Check primaryProcessId is in the list and unique
    // 7. Check no blocking measures on excluded processes
    // 8. Deactivate existing links (fill unlinkedAt)
    // 9. Create new risk_processes for selected processIds
    // 10. Set isPrimary = true on primaryProcessId
    // 11. Update assessment.responseMode = "split"
    // 12. Return riskId, responseMode
}

// POST /v1/risks/{id}/transfer
public async Task<TransferRiskResponse> TransferAsync(int riskId, int userId, TransferRiskRequest request, CancellationToken ct)
{
    // 1. Check transfer_risk permission
    // 2. Check status is "Open"
    // 3. Check active assessment with responseMode = null
    // 4. Check all treatments on current processes are terminal
    // 5. Check new process is active
    // 6. Update assessment.responseMode = "transfer"
    // 7. Deactivate current assessment (is_active = FALSE)
    // 8. Fill unlinkedAt for previous risk_processes
    // 9. Create new risk_process with isPrimary = true
    // 10. Clear acceptanceLevel
    // 11. Set risk status = "AwaitingReassessment"
    // 12. Return riskId, responseMode, riskStatus
}

// POST /v1/risks/{id}/reassess
public async Task<ReassessRiskResponse> ReassessAsync(int riskId, int userId, CancellationToken ct)
{
    // 1. Check edit_components permission
    // 2. Check status is "Accepted" or "Closed"
    // 3. For closed: warn about clearing closeReason
    // 4. Deactivate current assessment if exists
    // 5. Clear acceptanceLevel
    // 6. Clear closeReason if closed
    // 7. Set risk status = "AwaitingReassessment"
    // 8. If closed: create system comment
    // 9. Return riskId, riskStatus
}

// POST /v1/risks/{id}/close
public async Task<CloseRiskResponse> CloseAsync(int riskId, int userId, CloseRiskRequest request, CancellationToken ct)
{
    // 1. Check close_risk permission
    // 2. Check status is "Draft", "Open", "AwaitingReassessment", or "Accepted"
    // 3. Check no blocking measures
    // 4. Validate closeReason
    // 5. Atomically: update status = "Closed", closeReason, create system comment
    // 6. Return riskId, riskStatus
}

## Key Algorithm Details

### Accept
```
risk.status = "Accepted"
assessment.responseMode = "accept"
```

### Treat
```
assessment.responseMode = "treat"
```

### Split
```
// Deactivate old links
UPDATE risk.risk_processes SET is_risk_process_primary = FALSE, unlinked_at = NOW()
WHERE risk_id = @RiskId AND risk_process_id NOT IN (@SelectedProcessIds)

// Create new links
INSERT INTO risk.risk_processes (risk_id, risk_processed_owner_id, person_id, is_risk_process_primary)
VALUES (@RiskId, @OwnerUserId, @PersonId, TRUE) FOR selected processIds

assessment.responseMode = "split"
```

### Transfer
```
// Deactivate current assessment
UPDATE assessment.assessments SET is_active = FALSE WHERE risk_id = @RiskId

// Update old process links
UPDATE risk.risk_processes SET unlinked_at = NOW() WHERE risk_id = @RiskId

// Create new primary process link
INSERT INTO risk.risk_processes (risk_id, risk_processed_owner_id, person_id, is_risk_process_primary)
VALUES (@RiskId, @NewOwnerUserId, @NewPersonId, TRUE)

// Clear acceptance and set status
UPDATE risk.risks SET risk_acceptance_level = NULL, risk_status = 'AwaitingReassessment' WHERE risk_id = @RiskId
```

### Reassess
```
// Deactivate assessment
UPDATE assessment.assessments SET is_active = FALSE WHERE risk_id = @RiskId

// Clear fields
UPDATE risk.risks SET risk_acceptance_level = NULL, risk_close_reason = NULL WHERE risk_id = @RiskId

// Set status
UPDATE risk.risks SET risk_status = 'AwaitingReassessment' WHERE risk_id = @RiskId

// If was closed: create system comment
INSERT INTO risk.comments (comment_author_id, comment_text, comment_entity_type, comment_entity_id)
VALUES (@UserId, 'Риск возвращён на переоценку.', 'Risk', @RiskId)
```

### Close
```
// Atomic update
UPDATE risk.risks SET risk_status = 'Closed', risk_close_reason = @Reason WHERE risk_id = @RiskId

// Create system comment
INSERT INTO risk.comments (comment_author_id, comment_text, comment_entity_type, comment_entity_id)
VALUES (@UserId, 'Риск закрыт: ' + @Reason, 'Risk', @RiskId)
```
