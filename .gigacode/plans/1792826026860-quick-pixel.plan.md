# Plan: Treatment Management API (~15 endpoints)

## Overview
Implement full treatment lifecycle management:
1. `POST /v1/treatments` — Create treatment
2. `PUT /v1/treatments/{id}` — Edit draft treatment
3. `POST /v1/treatments/{id}/submit-approval` — Submit for approval
4. `POST /v1/approval-requests/{id}/approve` — Approve treatment
5. `POST /v1/approval-requests/{id}/reject` — Reject treatment
6. `POST /v1/approval-requests/{id}/revoke` — Revoke approval request
7. `POST /v1/treatments/{id}/execute` — Assign to executor
8. `POST /v1/treatments/{id}/replace-assignee` — Replace assignee
9. `POST /v1/treatments/{id}/remove-assignee` — Remove assignee
10. `POST /v1/treatments/{id}/start` — Start execution
11. `POST /v1/treatments/{id}/hold` — Hold treatment
12. `POST /v1/treatments/{id}/resume` — Resume from hold
13. `POST /v1/treatments/{id}/complete` — Complete treatment
14. `POST /v1/treatments/{id}/cancel` — Cancel treatment

## Key Design Decisions

### TreatmentStatus enum changes
Add 4 new statuses:
```csharp
public enum TreatmentStatus
{
    Planned = 1,        // Черновик (existing)
    PendingApproval = 5, // На согласовании (NEW)
    Approved = 6,       // Согласовано (NEW)
    AwaitingExecution = 7, // Ожидает выполнения (NEW)
    InProgress = 2,     // В работе (existing)
    Hold = 8,           // Холд (NEW)
    Completed = 3,      // Готово (existing)
    Cancelled = 4       // Отменено (existing)
}
```

### Treatment entity domain methods
Add methods for new status transitions:
- `SubmitForApproval()` — Planned → PendingApproval
- `Approve()` — PendingApproval → Approved
- `Reject()` — PendingApproval → Planned

- `AssignTo()` — update AssignedToId

## Key Algorithm Details

### Treatment Status Flow
```
Planned → [submit-approval] → PendingApproval → [approve] → Approved → [execute] → AwaitingExecution → [start] → InProgress → [complete] → Completed
                                                                    → [hold] → Hold → [resume] → InProgress
                                                          → [cancel] → Cancelled
PendingApproval → [reject] → Planned
PendingApproval → [revoke] → Planned (or Approved → Cancelled)
InProgress → [hold] → Hold
InProgress → [cancel] → Cancelled
```

### Approval Level Calculation
```
if (costPlanned <= ownerThreshold): level = "Owner"
else if (costPlanned <= directorThreshold): level = "Director"
else: level = "Ceo"
```

### Complete Last Treatment
```
activeTreatments = GetActiveTreatmentsOnRisk(riskId)
if (activeTreatments.Count > 1):
    treatment.status = "Completed"
    treatment.actualCost = costAct
else:
    treatment.status = "Completed"
    treatment.actualCost = costAct
    assessment.Deactivate()
    risk.ClearAcceptanceLevel()
    risk.SetStatus("AwaitingReassessment")
```
